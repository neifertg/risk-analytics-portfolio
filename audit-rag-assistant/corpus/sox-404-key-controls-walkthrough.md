# SOX 404 Key Controls Walkthrough

## Objective

Confirm that a key control identified in the SOX 404 risk-and-controls
matrix (RCM) is both suitably designed and operating effectively, so
management and the external auditor can rely on it when concluding over
internal control over financial reporting (ICFR).

## Phase 1: Design Effectiveness

Meet with the control owner and walk a single transaction end-to-end
through the control, from initiation to the point it's recorded. Confirm:
the control activity as performed matches the RCM's written description;
the control owner has the authority and system access needed to perform
it; and the control, if performed as described, would actually prevent or
detect a material misstatement — not just document that something
happened. Update the RCM narrative if the walkthrough surfaces a gap
between the documented control and the control as actually performed.

## Phase 2: Operating Effectiveness

Select a sample of instances where the control should have operated
during the testing period (see [Audit Sampling
Methodology](audit-sampling-methodology.md) for how sample size and
selection method are chosen) and test each instance for evidence the
control actually occurred — approval signatures, system timestamps,
exception reports reviewed and cleared. This step only starts once Phase
1 has confirmed the control is well-designed; testing operating
effectiveness on a control that isn't even properly designed wastes
effort on evidence that wouldn't matter anyway. A control that passes
Phase 1 but fails Phase 2 is a control that looks fine on paper but isn't
reliably performed; document it as an operating-effectiveness deficiency,
not a design deficiency.

## Deficiency Classification

Classify any exception found in either phase as a control deficiency,
significant deficiency, or material weakness based on the reasonable
possibility that a material misstatement would not be prevented or
detected. A single missed approval on a low-dollar, low-frequency control
is usually a deficiency; a broken control over a high-risk account with no
compensating control is a candidate for significant deficiency or worse.
Route the classification decision through the SOX PMO, not the individual
tester, since it affects the aggregate ICFR conclusion.
